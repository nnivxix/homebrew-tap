# nnivxix's Homebrew Tap

Personal [Homebrew](https://brew.sh) tap for tools by [nnivxix](https://github.com/nnivxix).
Install any app with `brew install nnivxix/tap/<app>`.

| App | Description | Install |
| --- | --- | --- |
| [gorbang](https://github.com/nnivxix/gorbang) | Terminal UI to find and kill processes listening on TCP ports | `brew install nnivxix/tap/gorbang` |
